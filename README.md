## 🔍 About the Project

This project predicts **precipitation levels** (in millimeters) using historical weather data. It leverages **machine learning algorithms** to help interpret patterns and trends in weather behavior — not just whether it rains or not, but *how much* it might rain.

---

## 🧠 Machine Learning Models Used

| 🔧 Model              | 💡 Approach     | 🔍 Purpose                       |
|----------------------|----------------|----------------------------------|
| K-Nearest Neighbors  | Regression     | Predict numerical precipitation  |
| Decision Tree        | Regression     | Tree-based precipitation estimate |
